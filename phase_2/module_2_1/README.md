Module 2.1: Algebra & Functions (Weeks 9–12)This module bridges foundational algebra with computational modeling, translating mathematical functions into Python code to prepare for advanced topics like Ordinary Differential Equations (ODEs) in neuroscience.
📈 Core Functions & What They RepresentLinear: Constant rates of change; baseline trends.Quadratic: Accelerating changes or optimization curves.Exponential (Growth/Decay): Systems where change depends on current size (e.g., rapid growth or fading out).Trigonometric Periodic, repeating cycles and oscillations.💻 Projects OverviewFunction Plotting: Using matplotlib to visualize linear, quadratic, exponential decay, and sine wave trajectories.Equation Evaluator: A Python function that evaluates an equation across a dense array of points simultaneously.Why it's useful: Instead of calculating single static inputs, evaluating across multiple points allows us to simulate continuous time, space, and dynamic signals.
🧠 Connection to NeuroscienceExponential Decay: Models how a neuron's membrane voltage decays back to its resting potential after an electrical jolt, as well as neurotransmitter clearance at the synapse.Trigonometric Functions: The mathematical foundation for brain waves. EEG data is analyzed as a mix of overlapping sine and cosine oscillations (Alpha, Beta, Theta rhythms).Algebraic Manipulation: The strict prerequisite for computational neuroscience. Rearranging equations is essential for coding biophysical models like the Hodgkin-Huxley equations.
