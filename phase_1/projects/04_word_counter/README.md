# Word frequency counter

A word frequency counter that allows users to clean text from a file, also allows the user to see how many times each unique word appears.

## How it works
- The script reads the content of a file named sample.txt and converts it to lower case
- then it splits the text into individual words and strips away any punctuation. Then it loops through the words to count their occurrences and prints the final dictionary.


## How to run
python word_count.py

## What I learned
- How to clean text by stripping away explicit punctuation marks.
- Dictionaries are fundamental to data analysis — mapping keys to values allows us to track frequencies efficiently.
