# Traffic light

A traffic light that allows users to control the state of traffic,also allows the user to tell it when to stop.

## How it works
- The first colour shows and its red
- then the user is asked to continue or stop , is he chooses continue then the next will be green. Then after green it moves to yellow then from yellow goes back to red.


## How to run
python traffic_light.py
