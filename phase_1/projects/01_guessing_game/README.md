# Number Guessing Game

A command-line game where the computer picks a random number between 1-100 
and the user tries to guess it.

## How it works
- Computer picks a random number between 1 and 100
- User keeps guessing until they get it right
- After each wrong guess, the program says "too high" or "too low"
- At the end, the program shows how many guesses it took

## How to run
python guessing_game.py
